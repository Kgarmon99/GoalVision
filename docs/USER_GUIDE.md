## Getting Started

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- Screen resolution of 1280x720 or higher (recommended)

### Accessing the Platform

1. Open your web browser and navigate to the application URL
2. The platform does not currently require login credentials
3. You will be directed to the Dashboard, which is the main interface

### First-Time Setup

If this is your first time using the platform, you'll be presented with a Quick Start Guide that will help you:

1. Create your first goal
2. Set up weekly tracking
3. Add execution tasks
4. Understand how to update progress

## Dashboard Overview

The Dashboard is your central hub for tracking goals, metrics, and tasks. It provides:

![Dashboard Overview](../public/images/dashboard-screenshot.png)

### Key Elements

1. **Navigation Bar**: Access different sections of the application
2. **Goal Progress Cards**: Visual representation of your goals and progress
3. **Metrics Sections**: Key metrics grouped by category (growth, revenue, etc.)
4. **Status Indicators**: Overall status of your goals
5. **Weekly Execution Tracker**: Tasks for the current week

### Action Buttons

- **Add Goal**: Create a new goal to track
- **Update Progress**: Update progress on existing goals
- **Track Execution**: Add tasks to help achieve your goals
- **Refresh Data**: Update the dashboard with the latest information

## Managing Goals

### Creating a New Goal

1. Click the "Add Goal" button in the navigation bar
2. Fill in the goal details:
   - **Name**: A descriptive title for your goal
   - **Current Value**: Your starting point
   - **Target Value**: The end goal you want to achieve
   - **Unit** (optional): The unit of measurement (e.g., M for million, % for percentage)
   - **Color**: Choose a color to visually identify this goal
   - **Deadline**: Set a target date for goal completion
3. Click "Add Goal" to create your goal
4. The new goal will appear on your Dashboard

### Editing Goals

Currently, direct editing of goals is limited. To modify a goal:

1. Update the progress using the "Update Progress" feature
2. For major changes, create a new goal and track progress there

### Deleting Goals

1. Locate the goal you want to delete on the Dashboard or Goal Visualizations page
2. Click the menu icon (three dots) on the goal card
3. Select "Delete"
4. Confirm the deletion when prompted

**Note**: Deleting a goal is permanent and will also remove associated status data.

## Tracking Progress

### Updating Goal Progress

1. Click the "Update Progress" button in the navigation bar or click on a goal card
2. Select the goal you want to update
3. Enter the new current value
4. The system will automatically:
   - Calculate the new progress percentage
   - Update visualizations
   - Update related metrics
   - Trigger celebrations if the goal is achieved

### Understanding Progress Indicators

Goals use color-coded indicators to show progress:

- **Green**: 75-100% complete (on track or completed)
- **Yellow**: 50-74% complete (making good progress)
- **Orange**: 25-49% complete (needs attention)
- **Red**: 0-24% complete (significant effort needed)

### Deadline Tracking

Goals with deadlines display additional information:

- Dates in the future: Shows days remaining
- Approaching deadlines (within 7 days): Marked as "urgent"
- Overdue dates: Marked as "overdue"

## Task Management

The Task Board provides a Kanban-style interface for managing execution tasks.

### The Task Board

![Task Board](../public/images/task-board-screenshot.png)

The board is divided into three columns:
1. **In Progress**: Tasks currently being worked on
2. **Completed**: Tasks that have been finished
3. **Missed**: Tasks that were not completed by the deadline

### Creating Tasks

1. Click the "Add Task" button in the navigation bar or on the Task Board
2. Fill in the task details:
   - **Task Description**: What needs to be done
   - **Goal Category**: Associated goal or category
   - **Owner**: Person responsible
   - **Due Date**: When the task should be completed
   - **Week**: The week this task belongs to
3. Click "Add Task" to create the task

### Managing Tasks

1. **Drag and Drop**: Move tasks between columns to update their status
2. **View Details**: Click on a task to see details and subtasks
3. **Filter and Sort**: Use the controls at the top of the Task Board to:
   - Filter by status or goal category
   - Sort by due date or goal category
4. **Task Priority**: Tasks are automatically prioritized based on:
   - Due date (overdue tasks are highest priority)
   - Goal category importance
   - Manual priority settings on subtasks

### Working with Subtasks

1. Click on a task to open its details
2. In the Task Details page, you can:
   - View the main task information
   - Add subtasks using the "Add Subtask" form
   - Mark subtasks as completed
   - Set priority levels for subtasks

## Visualizing Goals

The Goal Visualizations page provides various ways to analyze your goals.

### Accessing Visualizations

Click on "Goals" in the navigation bar to access the Goal Visualizations page.

### Visualization Types

1. **Area Chart**: Shows progress over time with filled areas
2. **Bar Chart**: Compares goals side by side
3. **Pie Chart**: Shows proportional distribution
4. **Line Chart**: Tracks trends over time
5. **Radial Chart**: Circular progress visualization
6. **Forecasting**: Predictive analysis based on current progress

### Using Visualizations

1. Select a goal to focus on
2. Choose a visualization type using the chart type selector
3. View goal details and metrics
4. Toggle between different views (grid/list)
5. Filter and sort goals using the controls at the top

### Analyzing Goal Relationships

The Goal Visualizations page also provides:

1. **Goal Dependencies**: Visual representation of how goals relate to each other
2. **Impact Analysis**: Which goals have the highest impact on overall success
3. **Trend Analysis**: How goal progress is changing over time

## Weekly Planning

The Weekly Execution Tracker helps you plan and track tasks on a weekly basis.

### Weekly View

1. Navigate to the Dashboard to see the current week's tracker
2. Use the arrow buttons to navigate between weeks
3. View tasks organized by:
   - Task status
   - Goal category
   - Due date

### Creating a New Week

Weeks are automatically created when you add tasks. To specify a new week:

1. Click "Add Task" in the navigation bar
2. In the Week dropdown, select "Create New Week"
3. Enter the week number and date range
4. Continue with task creation

### Tracking Weekly Performance

Each week displays:

1. **Completion Rate**: Percentage of tasks completed
2. **Task Status Breakdown**: Visual breakdown of task statuses
3. **Goal Progress**: How this week's tasks contribute to goal progress

## Tips and Best Practices

### Goal Setting

1. **Be Specific**: Set clear, measurable goals with specific targets
2. **Use Realistic Deadlines**: Set challenging but achievable deadlines
3. **Break Down Large Goals**: Use tasks and subtasks to break down big goals
4. **Balance Categories**: Create goals across different areas (revenue, growth, etc.)

### Progress Tracking

1. **Regular Updates**: Update progress at least weekly
2. **Use Metrics**: Pay attention to the metrics section for insights
3. **Track Trends**: Notice trends in your progress over time
4. **Celebrate Achievements**: Take note when you achieve or exceed goals

### Task Management

1. **Weekly Planning**: Plan your tasks at the start of each week
2. **Prioritize**: Focus on high-impact tasks first
3. **Use Subtasks**: Break complex tasks into smaller, manageable subtasks
4. **Update Statuses**: Keep your task board updated to reflect reality

## Troubleshooting

### Common Issues

1. **Data Not Refreshing**
   - Click the "Refresh Data" button on the Dashboard
   - Check your internet connection
   - Try reloading the page

2. **Task Not Appearing in the Right Week**
   - Check the week assignment in the task details
   - Edit the task to assign it to the correct week

3. **Progress Not Updating Metrics**
   - Metrics are calculated automatically but may need time to update
   - Try clicking the "Refresh Data" button
   - If metrics still don't update, check that your goal is correctly categorized

4. **Visualization Not Showing All Goals**
   - Check if any filters are applied
   - Try different visualization types
   - Ensure goals have progress values entered

### Getting Help

If you encounter issues not covered in this guide:

1. Check the console logs for any error messages
2. Look for updates to the application
3. Contact the system administrator for assistance
